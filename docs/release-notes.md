- 拉动时固定发根、保留发梢弯钩和厚度，超过伸长或弯曲限制后产生阻力，松手后回弹恢复卷曲。

验证：107 项逻辑测试；真实 Electron 三种尺寸、贴边/悬浮交互与 288 组极限拉拽组合；向上拉动、松手恢复和睡眠画面检查。

# v0.6.7 — 睡眠细节、揉眼与呆毛绑定

- 睡眠时每隔约 2.5–6 分钟随机抖动一只耳朵；呼吸周期 20–28 秒、幅度极小，呆毛低频轻摆，偶尔缓缓换向。
- 点击唤醒时约 12% 概率触发小手揉眼、缓慢睁眼，其他唤醒动作保留；控制台预览同步支持。
- 呆毛改为沿发丝走向的条带网格，固定发根，抓点随鼠标，先顺直再有限弹性拉伸，松手回弹。
- 同时扩展 WebGL 画布和透明窗口的留白，保留角色显示尺寸、贴边位置、透明区域穿透与旧设置位置。

验证：103 项逻辑测试；真实 Electron 三种尺寸、贴边与悬浮交互，以及 192 组极限拉拽/姿态组合和揉眼慢睁眼画面检查。

# v0.6.6 — 点击唤醒与随机醒来动作

- 睡眠只响应点到角色的左键点击；靠近、揉动、滚轮与菜单活动不会唤醒。
- 每次从睡眠唤醒抽取一次动作：50% 慢慢醒来、30% 轻轻伸展、20% 左右张望。保持先睁眼再播放动作和抬头，结束后恢复正常跟随。
- 睡眠点击优先于拖动、眨眼和耳朵点击，避免唤醒时误触其他动作；控制台预览同步支持。

验证：97 项逻辑测试；真实 Electron 贴边与悬浮窗口的靠近不唤醒、点击唤醒及睁眼后动作。

# v0.6.5 — 揉头反应与闲置睡眠

- 每次揉头只抽取一次反应：20% 放松闭眼、50% 睁眼晃头并摆动呆毛、30% 轻微摇晃；离开不足 0.65 秒保持同一反应。
- 闭眼分支保留离开后随机 2–5 秒等待，以及双眼睁开后再移动的顺序；睁眼分支离开后自然收住动作，不进入闭眼等待。
- 闲置 2 分钟起抽取入睡时间，2 分钟时约 10% 入睡，其余概率随时间递增，最迟 10 分钟必定入睡。计时以和角色的鼠标互动为准，隐藏时间照常累计。
- 睡着后头部再降低约角色大小的 8.5%（悬浮时 2.5%），耳尖在萎靡姿态上再下垂，手仍搭在任务栏上；停止挪动和待机扑耳。
- 靠近移动、揉头、点击或拖动可唤醒；先睁眼，再抬起脑袋。长期把光标停在头顶也会结束揉头并进入闲置。

验证：92 项逻辑测试；Electron 贴边与悬浮模式的揉头反应、趴睡和唤醒画面检查。

# v0.6.4 — 睁眼后再移动

- 揉头后保留随机 2–5 秒闭眼等待，双眼恢复睁开并短暂停顿约 0.1 秒后才继续扭头和横向挪动；已开始的挪动会暂停并接着播放，闭眼期间不会累积下一步。
- 每次闭眼约 80% 同步、20% 随机选择先闭的眼睛；偶发时间差缩短至日常眨眼 10–25ms、揉头闭眼 25–65ms。
- 拖拽等主动操作仍可打断等待。

验证：78 项逻辑测试，覆盖概率、时差、30/60/120FPS 的睁眼与移动顺序、动作暂停恢复、久停和主动操作；Electron 贴边与悬浮画面验证。

# v0.6.0 — 揉头与细节动作

- 脑袋附近持续来回移动光标，先缓缓跟着晃动，约3秒后逐渐停稳、闭眼放松；移开后平滑睁眼并恢复。
- 视线增加小幅偏移；静止约7秒后淡出注视、逐渐萎靡。远离后也停止跟踪；附近重新移动会恢复。
- 点击耳朵的1–2次快速抖动：每次约115ms，加入耳根到耳尖的延迟传播、向内旋转和弯曲、短促反向回弹；耳根保持固定。
- 抬手高度由角色大小的8%降为2.5%，落地挤压和倾斜同步减轻。
- 保留呆毛提拽和耳朵点击，主动拖拽时不会误触发揉头。控制台预览使用同一套交互。

验证：66项逻辑测试；Chromium实际渲染与Electron揉头/离开/久停输入验证；150/240/460三档尺寸的贴边/悬浮呆毛、耳朵、拖拽交互回归通过。
