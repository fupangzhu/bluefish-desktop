# v0.6.0 — 揉头与细节动作

- 脑袋附近持续来回移动光标，先缓缓跟着晃动，约3秒后逐渐停稳、闭眼放松；移开后平滑睁眼并恢复。
- 视线增加小幅偏移；静止约7秒后淡出注视、逐渐萎靡。远离后也停止跟踪；附近重新移动会恢复。
- 点击耳朵的1–2次快速抖动：每次约115ms，加入耳根到耳尖的延迟传播、向内旋转和弯曲、短促反向回弹；耳根保持固定。
- 抬手高度由角色大小的8%降为2.5%，落地挤压和倾斜同步减轻。
- 保留呆毛提拽和耳朵点击，主动拖拽时不会误触发揉头。控制台预览使用同一套交互。

验证：66项逻辑测试；Chromium实际渲染与Electron揉头/离开/久停输入验证；150/240/460三档尺寸的贴边/悬浮呆毛、耳朵、拖拽交互回归通过。

蓝色肥鱼 v0.5.0：呆毛牵拉与情绪耳朵。

- **捏住呆毛提拽**：抓住的位置跟着鼠标，发根保持连接；先牵拉和拉直弯曲余量，再进入最多约 18% 的弹性拉伸，松手后阻尼回弹。
- **疼痛表情**：拉扯时眼睛变成 `> <`，松开后恢复。
- **左右耳独立交互**：点击哪只耳朵，哪只随机快速折动 1–2 次；拖动耳朵仍可移动角色。
- **待机扑耳**：每隔随机 60–120 秒，单耳轻轻扑闪一下；手动交互会延后下一次。
- **情绪耳姿态**：萎靡时双耳耷拉，兴奋时轻轻立高，再自然回落。
- **精确命中**：点击按变形后的发丝与耳朵判断，呆毛环内的空白和被遮挡区域不会误触。
- 支持贴边、悬浮及 150–460 大小；桌宠与控制台预览均可体验新交互。

验证：57 项逻辑测试通过；Electron 实际鼠标交互覆盖三种尺寸、贴边 / 悬浮、抓点跟随、情绪耳姿态及失焦恢复。
