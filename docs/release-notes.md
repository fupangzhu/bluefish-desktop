蓝色肥鱼 v0.5.0：呆毛牵拉与情绪耳朵。

- **捏住呆毛提拽**：抓住的位置跟着鼠标，发根保持连接；先牵拉和拉直弯曲余量，再进入最多约 18% 的弹性拉伸，松手后阻尼回弹。
- **疼痛表情**：拉扯时眼睛变成 `> <`，松开后恢复。
- **左右耳独立交互**：点击哪只耳朵，哪只随机快速折动 1–2 次；拖动耳朵仍可移动角色。
- **待机扑耳**：每隔随机 60–120 秒，单耳轻轻扑闪一下；手动交互会延后下一次。
- **情绪耳姿态**：萎靡时双耳耷拉，兴奋时轻轻立高，再自然回落。
- **精确命中**：点击按变形后的发丝与耳朵判断，呆毛环内的空白和被遮挡区域不会误触。
- 支持贴边、悬浮及 150–460 大小；桌宠与控制台预览均可体验新交互。

验证：57 项逻辑测试通过；Electron 实际鼠标交互覆盖三种尺寸、贴边 / 悬浮、抓点跟随、情绪耳姿态及失焦恢复。
