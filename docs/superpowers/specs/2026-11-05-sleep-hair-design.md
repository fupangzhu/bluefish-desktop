# 睡眠细节与呆毛交互

睡眠中单耳突然抖动的间隔为随机 150–360 秒，单次约 95ms，不唤醒；呼吸周期 20–28 秒，幅度低于原来的睡眠呼吸；呆毛以极低频率微摆，间隔 80–240 秒随机缓缓换侧。减少动态效果时停用。

唤醒增加约 12% 的揉眼睛分支：先保持闭眼，抬起圆手揉眼，随后缓慢睁开并落手。其余三组动作继续使用原来的睁眼顺序。桌面和控制台均显示。

呆毛使用源图透明度生成沿中心线的条带网格，固定真实发根并保持材质方向；保留先拉直、再最多 18% 轴向弹性、松手回弹。增加透明画布和原生窗口边距，保持可见角色大小、任务栏接触线和点击穿透。

验证长时钟、概率、揉眼时间线、材质方向、发根固定、抓点跟随、150/240/460 贴边与悬浮、极端拉拽完整性、失焦和原有交互回归。
