# 萎靡恢复时的侧瞥

用户已指定半垂眼皮、眼珠瞥向鼠标另一侧、角色向同一方向轻挪的表情。约 30% 的萎靡恢复触发一次，另外 70% 正常恢复；一次接近只抽签一次，至少间隔 30 秒。已睡着时继续使用原点击唤醒分支，靠近不唤醒睡眠。

反应持续约 3.6 秒：0.4 秒压低上眼皮并侧瞥，随后头部侧移角色尺寸的 2.5%，短暂停留，最后缓慢回到原位。方向在触发时锁定，与鼠标水平位置相反；正上方时朝显示器内侧，编辑器默认向左。侧瞥时上眼皮近似水平、虹膜略收窄；所有遮罩仍走修复后的连续眼睑渲染，禁止额外皮肤贴片。手保持搭在任务栏上。

Attention 中的 Reluctance 控制器只处理未睡眠的萎靡恢复；Motion 合成输出，Renderer 统一投影。反应期间暂停普通跟随挪动；拖动、揪呆毛、揉头和减少动态效果优先。编辑器新增左右侧瞥的确定性预览，使用同一状态机、时间轴和速度控制。
