# GitHub 首页排版

目标：以真实运行的角色与控制台为素材，统一首页的文字、图片、间距和视觉对齐。

采用纵向单栏：品牌与入口、任务栏跟随演示、揉头反应、闲置睡眠、下载与操作、控制台、源码说明。固定两栏表格仅用于简短操作映射，避免窄屏图片并排造成溢出。

所有主要图片使用同一外框宽度和中性色背景，内边距 32px；PNG 使用双倍分辨率，GIF 使用 800px 原生宽度。三种揉头状态以一个合成动画呈现，相同画布、同一基线、清晰标题。睡眠对比使用同一任务栏高度，小手对齐。

保留角色原有颜色；素材来自现有程序的真实渲染。文档改版不改角色资产。用户补充的点击唤醒要求同时纳入：睡眠只接受左键点击，50% 慢慢醒来、30% 轻轻伸展、20% 左右张望，双眼睁开后播放。

下载入口区分 GitHub 当前发布版 v0.5.0 与 main 源码 v0.6.6，不暗示旧安装包已含新功能。

验证：GitHub 渲染后的标题、链接、图片加载；桌面及 375px 窄屏的内容边缘、图片宽度、表格溢出；检查动画首尾与静态对齐。最终推送 main。
