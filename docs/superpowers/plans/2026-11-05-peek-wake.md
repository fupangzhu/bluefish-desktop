# Peek Wake Implementation Plan

**Goal:** Three random wake outcomes with a protected real wake after a brief left-side peek.

**Architecture:** Let Attention ask Wake for a decision before changing the Sleep latch. Wake owns outcome selection, animation and the 15-second guard. Motion applies the eye/ear overrides; the ear renderer accepts a separate left-side pose. Both existing UI surfaces keep using the shared pipeline.

**Tech Stack:** JavaScript, Canvas/WebGL, Electron.

**Spec:** docs/superpowers/specs/2026-11-05-peek-wake-design.md
